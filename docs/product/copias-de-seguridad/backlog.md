## HIT-002 — Copias de seguridad y restauración

- **HU-010 · Pendiente:** Como usuario, quiero crear desde una nueva vista una copia de la base de datos y las imágenes, para conservar su estado.
- **HU-011 · Pendiente:** Como usuario, quiero descargar una copia de seguridad en mi equipo, para conservarla fuera del servidor.
- **HU-012 · Pendiente:** Como usuario, quiero restaurar la base de datos y las imágenes desde una copia de seguridad, para recuperar un estado anterior.
- **HU-013 · Pendiente:** Como usuario, quiero automatizar las copias en el servidor indicando su frecuencia y el máximo de copias almacenadas, para mantener respaldos periódicos con retención limitada.
