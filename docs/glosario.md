# Glosario

- **Receta**: Un conjunto de ingredientes y pasos para preparar un plato específico.

- **Planificación de comidas**: El proceso de organizar qué comidas se prepararán durante la semana, almuerzos y cenas.

- **Lista de la compra**: Un listado de los ingredientes y productos necesarios para preparar las comidas planificadas o productos necesarios para el hogar.

- **Consejos culinarios**: Sugerencias o recomendaciones para mejorar la preparación de los alimentos, técnicas de cocina, o formas de optimizar el tiempo en la cocina.

- **Usuario**: Persona que utiliza la aplicación web para planificar comidas, compartir recetas y gestionar la lista de la compra.

- **Semana**: Un período de siete días que se utiliza como referencia para la planificación de comidas y la organización de la lista de la compra, que comienza el lunes y termina el domingo.

- **Etiqueta alimentaria**: Término que identifica un alimento concreto, un tipo de alimento o un grupo de alimentos, utilizado para clasificar recetas y organizar la planificación semanal. Una receta puede tener asociadas varias etiquetas alimentarias.

Por ejemplo:

| Receta | Etiquetas alimentarias |
| Potaje de judías | Legumbres, Judías |
| Sardinas al horno | Pescado, Sardinas |
