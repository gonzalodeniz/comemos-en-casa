# Planes y tareas

- `docs/planes/`: propuestas de alcance y criterios de aceptación. Un plan puede quedar pendiente de aprobación; [arquitectura-base](arquitectura-base.md) ya está aprobado, pero mover un plan aquí **no** lo aprueba ni inicia su ejecución.
- `odd/tasks/`: documentos de tareas de ejecución, uno por iniciativa que requiera seguimiento. Se crean **cuando se autoriza implementar** la iniciativa, enlazando el plan aprobado; no duplican aquí el texto del plan.

Las historias de usuario y decisiones de producto permanecen en `docs/`. La arquitectura tiene un [documento de tareas](../../odd/tasks/architecture-foundation.md); sus tareas permanecen pendientes hasta comenzar la ejecución.
