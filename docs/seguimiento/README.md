# Seguimiento local

Los seguimientos nuevos de iniciativas y los informes de auditoría se guardan aquí según `docs/process/FLUJO_DE_TRABAJO.md`. Los registros ya existentes en `odd/tasks/` permanecen allí: no crear duplicados ni trasladarlos automáticamente.

Crear un documento de tareas requiere un plan aprobado y una solicitud expresa de tareas o autorización de implementación. La única excepción es un borrador pedido expresamente, que queda pendiente de aprobación y no autoriza implementar. Cada registro debe enlazar su historia y plan, indicar qué se ha autorizado y conservar evidencia y limitaciones.
