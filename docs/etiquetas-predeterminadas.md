# Etiquetas alimentarias predeterminadas

La planificación de comidas (HU-002) utiliza inicialmente este catálogo compartido de etiquetas. Cada etiqueta puede seleccionarse para un almuerzo o una cena; la creación o edición de etiquetas por parte de los usuarios queda para una funcionalidad posterior.

| Grupo orientativo | Etiquetas disponibles |
| --- | --- |
| Legumbres | Legumbres, Garbanzos, Lentejas, Judías |
| Pescados y mariscos | Pescado, Sardinas, Marisco |
| Carnes | Carne, Pollo, Ternera, Cerdo |
| Verduras y hortalizas | Verduras, Ensalada |
| Otros platos | Pasta, Arroz, Huevos, Sopa, Pizza |

Los grupos solo organizan esta lista para su lectura: **cada nombre de la tabla es una etiqueta independiente**. Por ejemplo, «Pescado» y «Sardinas» son opciones distintas; elegir una no asigna la otra. La lista no presupone que los usuarios puedan crear, editar o borrar etiquetas en esta etapa.
