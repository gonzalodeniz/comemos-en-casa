## HIT-002 — Copias de seguridad y restauración

- **HU-010 · Hecha:** Como usuario, quiero crear desde una nueva vista una copia de la base de datos y las imágenes, para conservar su estado. [Criterios y validación](../../historias-usuarios/HIT-002-copias-de-seguridad/HU-010-crear-copia-de-seguridad.md).
- **HU-011 · Pendiente:** Como usuario, quiero descargar una copia de seguridad en mi equipo, para conservarla fuera del servidor.
- **HU-012 · Hecha:** Como usuario, quiero restaurar la base de datos y las imágenes desde una copia de seguridad, para recuperar un estado anterior. [Criterios y validación](../../historias-usuarios/HIT-002-copias-de-seguridad/HU-012-restaurar-copia-de-seguridad.md).
- **HU-013 · Pendiente:** Como usuario, quiero automatizar las copias en el servidor indicando su frecuencia y el máximo de copias almacenadas, para mantener respaldos periódicos con retención limitada.
