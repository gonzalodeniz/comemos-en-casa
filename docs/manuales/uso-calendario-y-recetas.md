# Manual de uso: calendario y recetas

La aplicación ofrece un calendario semanal compartido y un catálogo público de recetas. Todas las recetas son visibles públicamente; no existe visibilidad privada ni un catálogo restringido a familias.

## Calendario semanal

1. Abre la aplicación.
2. Consulta la semana actual en la cuadrícula de lunes a domingo.
3. Usa **Semana anterior**, **Semana actual** o **Semana siguiente** para navegar.
4. Selecciona una celda para crear una asignación.
5. Elige una receta pública o introduce texto libre.
6. Guarda la asignación. Las asignaciones existentes pueden editarse o eliminarse.

El calendario usa `Europe/Canary` para calcular la semana actual. El modo invitado está habilitado por defecto y todas las visitas utilizan el calendario compartido.

## Catálogo público de recetas

1. Escribe un título o parte del título en el buscador.
2. La búsqueda ignora mayúsculas, minúsculas y acentos.
3. Selecciona una receta para consultar su detalle actual.
4. El título, la imagen y el detalle se leen del catálogo; el calendario no guarda copias de esos datos.

## Disponibilidad de una receta

Si una receta asignada deja de estar disponible, la asignación se conserva como registro histórico y se muestra como **Receta no disponible**. No se elimina automáticamente la asignación.

## Alcance actual

- Disponible: consulta pública, búsqueda, detalle y asignaciones del calendario.
- Disponible: creación, edición y eliminación de asignaciones.
- Pendiente: gestión completa de recetas, borradores, colecciones y favoritos.
- No previsto: recetas privadas, visibilidad familiar o controles equivalentes de privacidad.
